# 走 Cloudflare 优选 IP 的 PT 站点域名 —— 参考基线（不是运行期状态）

# 运行期的真源在设备上：<数据目录>/cfopt-domains.txt
# 这份文件只是给人看的基线：把本机清单与它 diff 一下，就知道哪些站加过、哪些早该删。
#   · 整份推到设备：<应用安装目录>/cmd/main cfopt-domains import <这份文件>
#   · 按实测结论删掉「非 CF」条目：<应用安装目录>/cmd/main cfopt-domains prune
#
# 口径（别改）：
#   · 只收**套 Cloudflare** 的站点：注入会把域名解析到优选 IP，非 CF 站点会直接打不开；
#   · 写裸域 example.com 即覆盖该域及其所有子域；写 *.example.com 只覆盖一级子域；
#   · 每个域名都要做一次 TLS 实测选 IP，条目越多启动越慢（272 条那次把
#     hdwing / ourbits / 1ptba 打挂过，见 README「按域名选 IP」）。
